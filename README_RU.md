# Uncharted — аудитор целостности графиков

Uncharted — приложение на Streamlit для анализа того, как настройки графика влияют на восприятие данных. Оно строит графики из CSV, проверяет конкретные признаки риска и сравнивает выбранный вариант с рекомендованным масштабом. Найденный сигнал означает, что настройку стоит проверить; он не доказывает намерение ввести читателя в заблуждение.

## Демо и скриншоты

- **Онлайн-демо:** приложение пока не опубликовано. Ссылка будет добавлена после публикации.
- **Скриншоты:** добавим после появления публичного демо.

Не загружайте в публичное демо конфиденциальные, персональные или регулируемые данные. Код приложения анализирует загруженный CSV в активной сессии и сам не записывает файл на диск и не отправляет его сторонним сервисам. Это не является гарантией обработки данных облачной платформой — используйте только несекретные примеры.

## Возможности

- Загрузка CSV, просмотр таблицы, количества строк и столбцов, подсчёт пропусков.
- Полный интерфейс на русском и английском; русский выбран по умолчанию.
- Построение столбчатых, линейных и точечных графиков, гистограмм и box plot на Plotly.
- Выбор столбцов, редактирование заголовка и подписей осей, настройка диапазона исходного графика.
- Аудит с доказательствами, численными результатами, рекомендациями и ограничениями.
- Сравнение исходного графика с рекомендованным масштабом.
- Экспорт отчёта в CSV и JSON, а каждого графика — в интерактивный HTML.

## Проверки аудита

- Базовая линия и диапазон столбчатой диаграммы: обрезка данных и исключение нуля.
- Оценка визуального усиления различий: рассчитывается для положительных столбцов, когда это математически осмысленно.
- Видимость значений по оси: обрезка значений для линейных, точечных, box-графиков и диапазона X гистограммы.
- Пропущенные на графике строки: подсчёт строк, исключённых из-за отсутствующих или непригодных данных.
- Порядок X линейного графика: проверка сортировки числовых и датоподобных значений.
- Пригодность графика: постоянные значения и более 20 категорий в столбчатой диаграмме отмечаются для проверки.
- Повторяющиеся категории столбчатой диаграммы: сигнал о возможном наложении столбцов; автоматической агрегации нет.
- Потенциально влиятельные экстремальные значения: проверка по 3×IQR и отношению диапазона к IQR не менее 10.

Проверки не определяют намерения автора, не учитывают все предметные соглашения и не инспектируют изображения графиков. Пороговые значения — эвристики для проверки, а не универсальные правила.

## Запуск на Windows

Откройте PowerShell в папке проекта:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```

Для примера загрузите `examples/uncharted_demo.csv`. Если используете другую поддерживаемую версию Python, выберите ту же версию в настройках Streamlit Community Cloud.

## Тесты и синтетическая оценка

```powershell
python -m unittest discover -s tests -v
python -m evaluation.benchmark
```

Бенчмарк содержит 21 специально созданный сценарий для пяти типов графиков. Записанный результат — 87 совпавших из 87 ожидаемых статусов. Это не оценка качества на реальных данных и не основание заявлять общую точность, precision, recall или F1-score. Подробности: [`evaluation/README.md`](evaluation/README.md).

## Ограничения

- Приложение строит графики из CSV, но не анализирует загруженные изображения.
- Одновременно строится график одной выбранной меры; нет круговых диаграмм и сравнения шкал нескольких рядов.
- Проверки показывают сигналы для просмотра, а не вердикт о корректности данных или намерениях автора.
- Пропуски считаются, но приложение не определяет причину их появления.
- Публичное облачное демо не следует использовать для конфиденциальных данных.
